# A very simple sprite designer for the Tatung Einstein

This is a very simple sprite designer for the Tatung Einstein. Essentially it produces a grid and then allows you to specify which cells are set or blank and then calculates the required numbers required to create the sprite.

High level overview:

Written in Hisoft C on an Einstein with a dodgy control key.

Run S.COM to load the designer.

Run "ED S.C" to view the source code.

Run HC S.C to build the designer. Currently returning a Bad Data error so I suspect I am missing part of the command line.


The Hisoft C manual is available here https://www.cpcwiki.eu/imgs/a/a0/Hisoft_C_%28Hisoft%29_Manual.pdf
